# Publish Info — Kenapa kereta tidak tergelincir?

## Usulan Judul
Kenapa kereta tidak tergelincir?

## Deskripsi
Bagaimana bisa kereta yang berjalan di rel lurus mampu berbelok tanpa menggunakan kemudi? Roda kereta api umumnya diarahkan di sepanjang jalur menggunakan penampangnya yang berbentuk kerucut. Tanpa bentuk kerucut tersebut, roda akan melaju lurus karena kelembaman dan bergerak menuju rel luar di tikungan.
