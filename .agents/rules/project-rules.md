# Motion-Graphic Studio — aturan proyek

Sebelum mengerjakan apa pun di repo ini, baca dan patuhi `docs/AG-RULES.md`. Ringkasnya:
- Kerjakan hanya fase yang diminta, lalu laporkan di `docs/PROGRESS.md`, commit, push branch fase, dan berhenti.
- Jangan membaca atau mengubah `.env.local`. Jangan force-push, reset --hard, atau git clean.
- `docs/PRD.md` tidak boleh diubah; usulan ditulis di `docs/DECISIONS.md`.
- DONE hanya jika semua kriteria teruji dan ada bukti di `out/review/<fase>/`; selain itu PARTIAL.
- Batas ±400 baris per file; inti mesin `src/core/` tidak bergantung pada UI.
